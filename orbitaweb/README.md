# Orbita Web

색상 칩을 회전 원판에 배치해 브라우저에서 직접 연주하는 5트랙 원형 시퀀서입니다. 최대 3개의 Orbita를 만들고 각 원판에 독립적인 음원과 BPM을 지정할 수 있습니다.

## 실행

별도 런타임 라이브러리는 필요하지 않습니다. Finder에서 `index.html`을 더블클릭해 Safari로 바로 실행할 수 있습니다.

개발 서버를 사용하려면 프로젝트 폴더에서 다음 명령을 실행합니다.

```bash
npm run serve
```

브라우저에서 `http://localhost:4173`을 엽니다.

Node와 npm이 경로에 없는 Codex 환경에서는 다음처럼 실행할 수 있습니다.

```bash
python3 -m http.server 4173
```

## 테스트

```bash
npm test
```

외부 패키지는 설치하지 않으며 Node의 기본 테스트 러너를 사용합니다.

소스 수정 후 더블클릭용 단일 스크립트를 다시 생성하려면 다음 명령을 실행합니다.

```bash
npm run build
```

## 사용법

- 팔레트의 색상 칩을 클릭하면 가운데 트랙 음을 미리 듣고, 원판으로 드래그하거나 클릭해 배치합니다. 배치 직후에는 실제 트랙 음이 재생됩니다.
- 원판 위 칩을 다시 드래그하면 트랙과 재생 시점이 바뀝니다.
- 원판 위 칩을 각 Orbita 팔레트 오른쪽의 `DROP` 쓰레기통으로 끌어 놓으면 삭제됩니다.
- 기본 `16 STEP` 모드는 가장 가까운 16분음표에 맞추며 `FREE`는 자유 각도를 사용합니다.
- 칩을 선택한 뒤 방향키로 이동하고 `Delete` 또는 `Backspace`로 지울 수 있습니다.
- 모바일에서는 칩을 길게 눌러 삭제 메뉴를 표시할 수 있습니다.
- 원판의 재생 버튼은 개별 재생, 상단 버튼은 모든 원판의 동시 시작·정지입니다.
- BPM은 40–200 범위에서 슬라이더나 숫자 입력으로 조정하며 두 입력은 항상 동기화됩니다.
- `+` 버튼으로 Orbita를 최대 3개까지 추가합니다.
- 데스크톱에서는 Orbita 3개가 한 화면에 함께 표시되고, 모바일에서는 포커스 보기와 3개 전체 보기를 전환할 수 있습니다.
- 프로젝트는 브라우저에 자동 저장되며 JSON으로 내보내거나 불러올 수 있습니다.

브라우저 자동 재생 정책 때문에 첫 재생은 반드시 사용자 클릭이나 터치로 시작해야 합니다.

## 음원

현재 버전은 Web Audio API로 드럼, 피아노, Pluck Synth, 기타 음색을 가볍게 합성합니다. 실제 샘플 음원은 `src/audio/synth-voices.js`와 같은 `trigger(noteOrDrum, audioTime, options)` 계약을 구현하는 공급자로 교체할 수 있습니다. 시퀀서와 화면 코드는 음원 구현에 의존하지 않습니다.
